在新加坡工作，能不能带家人过去？家属准证 DP 和长期探访准证 LTVP 怎么办

新加坡2026-11-28羊驼出海

很多人去新加坡工作，最舍不得的就是家人。过去一段时间站稳脚跟后，就会想：能不能把老婆孩子接过来？

新加坡确实有给外籍员工家属的准证，最常见的是家属准证（Dependant's Pass，简称 DP）和长期探访准证（Long-Term Visit Pass，简称 LTVP）。但能不能办、能给谁办，主要看你持什么准证、收入多少。这篇帮你理清楚。

一、先看你自己的准证类型

新加坡的工作准证大致分几类，带家属的资格差别很大：

  • EP（就业准证）：收入达到一定标准的，可以为家属申请 DP 或 LTVP。
  • S Pass：同样要看收入是否达到标准。
  • Work Permit（工作准证）：一般不能为家属申请 DP 或 LTVP。

具体的收入门槛新加坡人力部（MOM）会调整，这里不写具体数字，以 MOM 官网最新标准为准。不清楚自己是哪种准证，可以先看 新加坡工作准证怎么选：EP、S Pass、Work Permit。

二、DP 和 LTVP 有什么区别

家属准证（DP）一般给：

  • 合法的配偶；
  • 未满 21 岁的未婚子女（包括合法领养的）。

长期探访准证（LTVP）一般给：

  • 事实婚姻的伴侣（common-law spouse）；
  • 继子女或残障子女等特殊情况；
  • 部分情况下，收入较高的准证持有人可以为父母申请。

简单记：配偶和孩子多数走 DP，其他家属走 LTVP。具体谁能申请哪种，以 MOM 官网为准。

三、谁来申请、怎么申请

和工作准证一样，家属准证通常由你的雇主或雇主委托的代理提交，不是你自己直接去申请。大致流程：

  1. 准备材料：家属护照、关系证明、照片等。
  2. 雇主在 MOM 系统提交申请。
  3. 等待审批：一般在线提交后会有结果，具体时间看情况。
  4. 获批后：家属入境新加坡，按通知完成录指纹、拍照等手续，然后领取准证卡。

一般可以和你自己的工作准证同时申请，也可以等你的准证批下来后再申请。

四、通常要准备的材料

  • 家属的护照：有效期充足。
  • 关系证明：
  • 配偶：结婚证；
  • 子女：出生证明（体现父母姓名）。
  • 翻译件：中文文件需要翻译成英文，并按要求做认证或公证。
  • 家属的近期证件照。
  • 其他补充材料：视情况可能需要，按 MOM 系统提示准备。

材料中最常出问题的是结婚证、出生证明的翻译和认证，建议提前办好。

五、家属能不能在新加坡工作

这是很多人最关心的问题：

  • 持 DP 的配偶，如果想在新加坡工作，一般需要雇主另外为他（她）申请工作准证，比如 EP、S Pass 或 Work Permit。
  • 家属准证本身不等于工作许可，千万不要拿着 DP 就直接上班，否则可能违法。

相关规定近年来有调整，具体以 MOM 官网为准。

六、孩子在新加坡上学

  • 持 DP 的孩子可以在新加坡上学。
  • 进政府学校需要参加入学考试或申请，名额有限，外国学生学费也比本地学生高。
  • 国际学校选择多、入学灵活，但学费较高。
  • 部分学校会要求额外的学生准证（Student's Pass），看具体情况。

七、几个常见问题

1. 我的准证续签了，家属的准证会自动续吗？

不会自动续，一般需要雇主同时为家属办理续签。家属准证的有效期通常和你的工作准证挂钩。

2. 我换工作了，家属准证怎么办？

你换雇主后，新雇主要重新为你申请工作准证，家属准证一般也需要重新申请。换工作的流程可以看 在新加坡想换工作，准证怎么办。

3. 家属能不能先来新加坡旅游，再在当地办？

有的情况下家属可以在新加坡境内完成手续，但具体要看申请类型和当时的规定，不要以为来了就一定能办，最好提前和雇主确认。

八、接家人之前想清楚的事

  • 住房：一家人住和一个人住差别很大，租金也高很多。
  • 孩子教育：学校怎么选，学费能不能负担。
  • 医疗：家属看病的费用和保险怎么安排。
  • 配偶的生活：如果配偶暂时不能工作，在新加坡的生活是否适应。

写在最后

能不能带家人去新加坡，关键看你的准证类型和收入。符合条件的话，DP 和 LTVP 是正规又稳定的方式。签工作合同时，也可以问问雇主是否愿意帮忙办理家属准证，这会让以后的安排顺利很多。
